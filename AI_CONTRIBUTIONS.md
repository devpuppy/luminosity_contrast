# AI-Assisted Development

This project uses AI tools, including OpenAI's ChatGPT and Codex, to assist with coding, testing, documentation, and maintenance.

The repository maintainer directs and reviews contributions and retains responsibility for all accepted changes.

## Commit Attribution

Substantial AI-generated contributions may be acknowledged using Git commit trailers:

```text
Co-authored-by: Codex <noreply@openai.com>
AI-Model: <model identifier>
```

Model identifiers are included only when reliably known. Minor AI assistance does not require attribution.
